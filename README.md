# ReserveGauge

ReserveGauge is a free native macOS menu-bar app for tracking AI-coding usage.
It shows live Claude Code and Codex limits, reset times, recent history and a
forecast of whether your current pace will last until reset. Grok and GitHub
Copilot are included too.

![ReserveGauge menu-bar forecast](https://reservegauge.com/assets/shots/popover-demo.webp)

## Download

- [Download the latest notarised DMG](https://github.com/Reservegauge/ReserveGauge/releases/latest)
- [Download from reservegauge.com](https://reservegauge.com/#get)
- Install with Homebrew:

  ```sh
  brew install --cask Reservegauge/tap/reservegauge
  ```

ReserveGauge requires macOS 13 Ventura or later and supports Apple Silicon and
Intel Macs. It is free, including forecasts. No account or card is required.

## Privacy

Usage history is stored on your Mac. Provider credentials are sent only to the
provider you selected, not to ReserveGauge. Read the full
[privacy policy](https://reservegauge.com/privacy).
